- **Subagents dispatch in the background:** the main thread must not launch a non-trivial subagent in the foreground — it blocks the orchestrator until the subagent finishes. Use `subagent_type: "fork"` or `isolation: "remote"` (both run in the background), or model the work as a Workflow; otherwise the dispatch is blocked (`background-subagent-gate`). For a real one-off exception, ask the human, or set `RIG_HATCH_REQUEST_BACKGROUND_SUBAGENT_GATE="<written justification>"` (deny-by-default; a bare `1` is rejected).
