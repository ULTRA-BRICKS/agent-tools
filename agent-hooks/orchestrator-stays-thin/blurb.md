- **Orchestrator discipline (enforced, not advisory):** this main thread plans, dispatches, and verifies — it does not implement inline. A non-trivial Edit/Write or multi-step Bash run directly on the main thread is blocked (`orchestrator-stays-thin`, warn-then-block); dispatch a subagent (`Agent` tool, `subagent_type: "fork"` or `isolation: "remote"`) or model it as a Workflow instead. Nearly all `gh` is delegated too — the one sanctioned exception is a genuinely UNCHAINED `gh ship <PR#>`, alone on the line. For a real one-off exception, ask the human, or set `RIG_HATCH_REQUEST_ORCHESTRATOR_STAYS_THIN="<written justification>"` (deny-by-default; a bare `1` is rejected).
