- **Package stores are shared, never cleaned:** disk-cleanup work must never wipe package-manager caches or stores (`bun pm cache rm`, `rm -rf ~/.bun/install/cache`, `uv cache clean`, `rm -rf ~/.cache/uv`) — every worktree's node_modules and venv links into them. In a bun repo install with `bun install --frozen-lockfile` (never `npm install`/`npm ci`, never a node_modules symlink to another checkout); reclaim disk by removing stale worktrees (`rig worktree gc`). Blocked by `package-store-guard`.
